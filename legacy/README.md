# Legacy prototypes

These are early standalone scripts kept for reference only. They predate the
current `visiondesk.py` / `app_ui.py` / `main.py` pipeline and are **not**
maintained.

| Script | What it was |
|--------|-------------|
| `screen_yolo_world.py` | First dual-monitor screen detector (YOLO-World + Supervision output stream) |
| `smoke_screen_yolo.py` | One-shot capture smoke test |
| `demo_annotate.py` | Minimal Supervision box-drawing example |

For the supported entry points, see the main [README](../README.md).
