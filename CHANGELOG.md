# Changelog

All notable changes to VisionDesk AI will be documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses semantic versioning.

## [Unreleased]

### Added

- Community contribution, security, issue, and pull-request guidance.
- Simplified Chinese README.
- CI status and release badges.

### Removed

- Two unused scratch scripts with corrupted source encoding.

## [0.1.0] - 2026-07-30

### Added

- Real-time screen and ROI capture.
- Adaptive YOLO detection and selective LocateAnything-3B reasoning.
- Event memory, snapshot replay, Gradio cockpit, and OpenCV desktop UI.
- Offline replay and benchmark tooling with YAML scene profiles.
- Multi-version syntax and critical-lint CI.
